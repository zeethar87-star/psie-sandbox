sandbox — the real gate

جرّب المنصة — Sandbox

دي مش محاكاة: ارفع ملف DXF خام (أو JSON مستخرج) والبوابة تشغّل الحصاد والتدقيق فعلياً على جهازك وتعرض الأرقام الحقيقية هنا — عائلات، علاقات ربطية، وتنبيهات الامتناع الثلاثية.

⌁
اسحب ملف DXF أو JSON أو PDF هنا أو دوس تختار
.dxf خام · .json مستخرج · .pdf للتنبيه الصادق — حتى 512MB
جاري التحليل على الخادم المحلي… ده شغل حقيقي، مش أنيميشن.
real compute in progress — expect ~20-35 s on large structural files

ملحوظة صادقة: الساند بوكس ده بيشتغل ضد البوابة المحلية على نفس الأصل (نفس الـorigin). لو فتحت الصفحة من file:// مش هيلاقي الخادم — شغّل الخادم المحلي أولاً: python product/qa_check/webapp/app.py ثم افتح http://localhost:8765. دعم PDF قادم مع نواة المرحلة ب — مش هنوهمك بيه دلوقتي.
